What Makes It Different

Everything you need to play Minecraft, nothing you don't.

JV

Auto Java Management

LackCityClient detects which Java version your Minecraft build needs and downloads it automatically. Java 8 for older versions, Java 17 for 1.17+, Java 21 for 1.20.5+, and Java 25 for the latest releases. No manual setup required.

VS

Full Version Support

Every Minecraft release and snapshot, from legacy versions all the way through the new year-based format. Whether you are playing 1.8.9 or the latest 26.2 drop, it is covered.

FL

Fabric Mod Loader

One-click Fabric installation with automatic library merging. Install mods from the Modrinth cloud browser or drop your own into the mods folder. Toggle, remove, and manage them from the built-in mods page.

MA

Multi-Account Support

Microsoft accounts, offline mode, and third-party auth servers. Switch between accounts instantly. Skin UUID and skin server support for customized profiles.

LV

Live Log Viewer

Full session logging with search, filtering by level, and export. Every stdout and stderr line from the game process is captured and displayed in real time. Debug crashes without leaving the launcher.

CP

Customizable Profiles

Upload a profile picture, set your skin, and personalize your launcher experience. Clean sidebar navigation with animated transitions between pages.
